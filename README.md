# ProtonVPN Scanner

ابزاری برای پیدا کردن سرورهای ProtonVPN که از نظر پینگ واقعاً در دسترس هستند، همراه با خروجی کانفیگ WireGuard.

## اجرا و تست روی macOS

### ۱. نصب Python 3.11

Kivy 2.3.0 (همان نسخه‌ای که در `buildozer.spec` استفاده شده) برای Python 3.11 و 3.12 بسته‌ی آماده دارد. Python 3.11 را توصیه می‌کنیم:

```bash
brew install python@3.11
```

یا از [python.org](https://www.python.org/downloads/) نسخه 3.11 را نصب کنید.

### ۲. ساخت محیط مجازی و نصب وابستگی‌ها

```bash
cd ProtonVPN-scanner
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
```

### ۳. اجرای تست‌های واحد

```bash
python -m unittest -v
```

تست‌ها فقط منطق برنامه (`scanner_core.py`) را بررسی می‌کنند و به رابط گرافیکی یا اینترنت نیاز ندارند.

### ۴. اجرای برنامه

```bash
python main.py
```

1. دکمه **1. LOAD DATABASE** را بزنید. دیتابیس از GitHub دانلود و کش می‌شود.
2. نوع سرور (FREE / PREMIUM / ALL) و در صورت نیاز کشور یا قاره را انتخاب کنید.
3. **2. START SCAN** را بزنید. **قبل از اسکن VPN را خاموش کنید**، چون پینگ باید مستقیم اندازه‌گیری شود.
4. روی هر سرور می‌توانید IP را کپی کنید، کانفیگ WireGuard را کپی کنید یا فایل `.conf` ذخیره کنید.
5. برای خروجی گرفتن از ۱۵ سرور برتر، **EXPORT TOP 15 (.conf)** را بزنید. مسیر فایل‌ها در نوار وضعیت نمایش داده می‌شود.

#### نکته درباره کلید خصوصی WireGuard

کلید عمومی هر سرور از دیتابیس خوانده می‌شود، اما کلید خصوصی باید از حساب ProtonVPN شما گرفته شود (بخش WireGuard در داشبورد Proton). اگر آن را وارد نکنید، در فایل‌ها `<PASTE_YOUR_PRIVATE_KEY>` قرار می‌گیرد و باید دستی جایگزین شود. این کلید فقط در حافظه‌ی برنامه نگه داشته می‌شود و ذخیره نمی‌شود.

### عیب‌یابی

- **`pip install kivy` خطای build می‌دهد**: معمولاً یعنی wheel برای نسخه Python شما نیست. Python 3.11 را از مرحله ۱ استفاده کنید. اگر لازم شد ابزارهای توسعه را نصب کنید: `xcode-select --install`.
- **macOS از شما اجازه‌ی شبکه می‌خواهد**: آن را بپذیرید؛ برنامه باید به GitHub و سرورهای ProtonVPN دسترسی داشته باشد.
- **دیتابیس لود نمی‌شود**: اینترنت یا فیلترینگ را بررسی کنید. اگر کش قدیمی وجود داشته باشد، برنامه از آن استفاده می‌کند.

## ساختار پروژه

| فایل | کاربرد |
| --- | --- |
| `main.py` | رابط گرافیکی Kivy |
| `scanner_core.py` | منطق بدون وابستگی به Kivy: دیتابیس، فیلترها، پینگ، کانفیگ WireGuard |
| `tests/test_scanner_core.py` | تست‌های واحد |
| `buildozer.spec` | تنظیمات ساخت APK برای اندروید |
| `requirements-dev.txt` | وابستگی‌های اجرا و تست روی دسکتاپ |

## ساخت APK

APK با GitHub Actions ساخته می‌شود (workflow با نام `Build Android APK`، اجرای دستی). پوشه `tests/` از APK حذف شده است.
